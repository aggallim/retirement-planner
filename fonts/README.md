# Fonts

Self-hosted so no visitor's request goes to Google (intent 060, privacy
review F5). Both are variable fonts, Latin subset, as served by Google Fonts,
and are precached by `sw.js`.

| File | Family | Licence |
|---|---|---|
| `fraunces-latin.woff2` | Fraunces (weights 100–900, optical size axis) | SIL Open Font License 1.1, `Fraunces-OFL.txt` |
| `inter-tight-latin.woff2` | Inter Tight (weights 100–900) | SIL Open Font License 1.1, `InterTight-OFL.txt` |

Characters outside the Latin subset fall back to the system font.
